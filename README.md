# Верстак 3D

Открытый 3D-редактор для 3D-печати в духе Tinkercad. Работает **без интернета** и без регистрации, на **Windows, macOS и Linux**. Интерфейс построен по образцу Microsoft Office: вкладка «Файл», лента с группами кнопок, панель «Формат» справа и строка состояния.

Лицензия — MIT: программу можно свободно использовать, изменять и распространять.

## Что умеет

- **17 фигур**: куб, скруглённый куб, цилиндр, шар, конус, пирамида, многогранник, клин, крыша, полуцилиндр, полусфера, параболоид, тор, труба, звезда, сердце, текст. У многих есть параметры (число граней, скругление, толщина стенки, глубина лучей звезды…).
- **Любая фигура может быть отверстием** — сердце, звезда, текст или импортированная модель. Поставьте её на тело и сгруппируйте — форма вырежется.
- **Объединение фигур, как в PowerPoint**: «Сгруппировать», «Вычесть» (из первой выбранной), «Пересечь» (оставить общую часть), «Разгруппировать».
- **Объёмный текст** любым шрифтом системы, с кириллицей, в несколько строк, полужирный и курсив, выравнивание.
- **Растягивание мышью**: белые квадраты по углам и сторонам, верхний — высота, стрелка — подъём над столом. Shift или кнопка «Сохранять пропорции» — без искажений.
- **Размеры прямо на модели**: щёлкните по числу у фигуры и введите миллиметры. Поддерживаются выражения: `40/3`, `20+2,5`. Стрелки ↑↓ меняют значение на 1 мм.
- **Увеличение и уменьшение**: поле «Масштаб, %», кнопки ±10 %, ×2, ½.
- Выравнивание, повороты на 90°, свободный поворот, отражение, **массив копий** (в ряд и по кругу), линейка, закрепление фигур, рамка выделения, Alt+перетаскивание — копия.
- **Стол принтера** (Ender-3, Prusa MK4/MINI, Bambu Lab X1/P1/A1/A1 mini, Kobra 2…) — программа предупредит, если модель не помещается. Оценка объёма и **массы пластика** (PLA, PETG, ABS, TPU).
- **Экспорт** в STL, 3MF (с цветами — для многоцветной печати) и OBJ. **Импорт** STL.
- Проекты сохраняются в файлы `.v3d` (обычный JSON). Двойной щелчок по файлу открывает его в программе. Автосохранение — после сбоя работа восстановится.
- Шаблоны: брелок с именем, стакан для карандашей, табличка-сердце, вырезанная надпись, коробочка.
- Светлая и тёмная темы.

### Чем отличается от Tinkercad

| | Tinkercad | Верстак 3D |
|---|---|---|
| Работа без интернета | нет | **да** |
| Учётная запись | обязательна | **не нужна** |
| Где хранятся проекты | в облаке Autodesk | **в ваших файлах** |
| Пересечение фигур | нет | **да** |
| Экспорт 3MF с цветами | нет | **да** |
| Масса пластика и проверка стола | нет | **да** |
| Массив по кругу | нет (только «повторить») | **да** |
| Ввод выражений в размерах | нет | **да** |
| Исходный код | закрыт | **открыт (MIT)** |

## Как получить программу

### Способ 1. Готовые установщики через GitHub (рекомендуется, без установки инструментов)

1. Создайте репозиторий на GitHub и загрузите в него эту папку.
2. Откройте вкладку **Actions** → «Сборка программы» → **Run workflow**.
3. Через 5–10 минут внизу страницы запуска появятся архивы:
   - **Windows** — `Verstak3D-Setup-1.0.0.exe` (установщик с ярлыком на рабочем столе) и `Verstak3D-Portable-1.0.0.exe` (без установки);
   - **macOS** — `Verstak3D-1.0.0-mac-arm64.dmg` (Apple M1–M4) и `…-mac-x64.dmg` (Intel);
   - **Linux** — `Verstak3D-1.0.0-linux-x86_64.AppImage` и `.deb`.

Если создать тег `v1.0.0` (`git tag v1.0.0 && git push --tags`), файлы автоматически появятся в разделе **Releases**.

### Способ 2. Собрать на своём компьютере

Нужен [Node.js](https://nodejs.org) 18 или новее (интернет нужен только для первой установки).

```bash
npm install          # один раз
npm start            # запустить программу
npm run dist         # собрать установщик для текущей системы → папка dist/
```

### Способ 3. Без установки — один HTML-файл

```bash
npm run web          # → dist-web/Verstak3D.html
```

Этот файл открывается двойным щелчком в Chrome, Edge, Firefox или Safari и тоже работает без интернета.

## Первый запуск неподписанной программы

Установщики не подписаны платным сертификатом, поэтому система предупредит один раз:

- **Windows**: «Windows защитила ваш компьютер» → **Подробнее** → **Выполнить в любом случае**.
- **macOS**: щёлкните по программе правой кнопкой → **Открыть** → **Открыть**. Если macOS пишет, что файл повреждён: `xattr -cr "/Applications/Verstak 3D.app"`.
- **Linux (.deb)** — рекомендуемый вариант для Ubuntu, Debian, Mint: `sudo apt install ./Verstak3D-*.deb`.
- **Linux (AppImage)**: `chmod +x Verstak3D-*.AppImage`, затем двойной щелчок. На Ubuntu 22.04 и новее сначала установите FUSE: `sudo apt install libfuse2` (на 24.04 — `libfuse2t64`). Если на Ubuntu 24.04+ AppImage не запускается из-за ошибки «SUID sandbox», запустите его с флагом `--no-sandbox` или установите `.deb`.

## Управление

| Действие | Как |
|---|---|
| Выбрать и двигать фигуру | левая кнопка мыши |
| Выделить несколько | Shift+клик или рамка по пустому месту |
| Вращать вид | правая кнопка мыши |
| Сдвинуть вид | средняя кнопка |
| Приблизить | колесо |
| Контекстное меню | короткий щелчок правой кнопкой |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Сгруппировать / разгруппировать | Ctrl+G / Ctrl+Shift+G |
| Отверстие / тело | H / S |
| Опустить на стол | D |
| Свободный поворот | E |
| Линейка | R |
| Текст | T |
| Показать всё | F |
| Справка | F1 |

## Устройство проекта

```
main.js              главный процесс Electron: окно, диалоги файлов, меню macOS
preload.js           безопасный мост окна к файловой системе
app/index.html       разметка интерфейса (лента, панели, Backstage)
app/styles.css       оформление, светлая и тёмная темы
app/js/core.js       геометрия: фигуры, текст, булевы операции (BSP-CSG), STL/3MF/OBJ
app/js/app.js        интерфейс: сцена, ручки, размеры, лента, файлы, клавиши
app/vendor/          three.js r128 (MIT) — входит в комплект, интернет не нужен
app/THIRD-PARTY-NOTICES.txt  лицензии сторонних компонентов
scripts/build-web.js сборка автономной веб-версии в один файл
.github/workflows/   автоматическая сборка установщиков для трёх систем
```

Перед публикацией замените в `package.json` поле `author` (имя и почту) на свои данные — они попадают в пакет `.deb` — и при желании строку `Copyright` в `LICENSE`.
